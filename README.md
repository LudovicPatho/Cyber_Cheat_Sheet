## 🔍 Information Gathering & OSINT

- **[Nmap](https://nmap.org/)** - Network scanner  
- **[Shodan](https://www.shodan.io/)** - Internet-wide scanner
- **[crt.sh](https://crt.sh/)** - A public web service for searching Certificate Transparency (CT) logs. Discovery sub domains.
- **[Censys](https://censys.io/)** - Internet asset search engine  
- **[Maltego](https://www.maltego.com/)** - Graph-based link analysis  
- **[theHarvester](https://github.com/laramies/theHarvester)** - Email and domain OSINT  
- **[Recon-ng](https://github.com/lanmaster53/recon-ng)** - Web reconnaissance framework  
- **[Amass](https://github.com/owasp-amass/amass)** - DNS enumeration and mapping  
- **[OSINT Framework](https://osintframework.com/)** - OSINT resource index  
- **[Hudson Rock](https://www.hudsonrock.com/search/domain/)** - Infostealer exposure search  
- **[Have I Been Pwned](https://haveibeenpwned.com/)** - Breach exposure checker  
- **[DeHashed](https://dehashed.com/)** - Credential leak intelligence
- **[snusbase](http://https://snusbase.com/)**  - Database leaked Search Engine
- **[Bonjour la fuite](https://bonjourlafuite.eu.org/)** - C’est qui qui a fuité aujourd’hui ?
- **[Social analyzer](https://github.com/qeeqbox/social-analyzer)** - Finding a person's profile across +1000 social media
- **[WhatsMyName](https://whatsmyname.io/)** - Finding all accounts by username
